DESCRIPTION
-----------
Two-photon imaging + visual stimulation rig for tethered Drosophila by Vasilis Kapantaidakis (JC Lab, University of Groningen). Basler GigE camera, FicTrac treadmill tracking, ViRMEn worlds on a conical screen, Arduino frame-trigger sync. Full setup and replication guide for Ubuntu 24.04 + MATLAB R2014b.
