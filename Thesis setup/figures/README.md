# Figures

Use this folder for approved setup figures and diagrams.

## Recommended figure/photo files

Upload only the images that are useful for documenting the final setup. Use descriptive names rather than phone-camera names.

| Recommended file name | What it should show | Use |
|---|---|---|
| `twophoton_screen_top_view.jpg` | Two-photon conical screen, top view. This corresponds to the first setup photo. | Documents the reduced two-photon screen geometry. |
| `twophoton_screen_large_top_view.jpg` | Two-photon conical screen with the rear-projection surface visible. This corresponds to the second setup photo. | Documents the inserted screen surface before/after replacing the paper with rear-projection film. |
