# Cone template

This folder contains the paper cone templates generated with Templatemaker.nl and used to check the screen midline/centering before inserting the rear-projection film.

## Templatemaker source

Use the cone/frustum template generator:

```text
https://www.templatemaker.nl/en/cone/
```

Set the page preset to A4 and the units to mm unless a different print setup is documented.

## Small screen template: two-photon screen

Use these values in Templatemaker.nl for the small screen used in the two-photon microscope setup:

```text
BOTTOM = 113 mm
TOP = 17 mm
H = 32 mm
PAGEPRESET = A4
UNITS = mm
```

Equivalent URL format:

```text
https://www.templatemaker.nl/en/cone/?BOTTOM=113&TOP=17&H=32&PAGEPRESET=A4&UNITS=mm
```

This template was used to make the paper insert for checking the midline/centering of the small two-photon screen. The inside paper/screen was later replaced by rear-projection film.

## Big screen template: behavioral arena screen

Use these values in Templatemaker.nl for the big screen used in the behavioral arena:

```text
BOTTOM = 226 mm
TOP = 34 mm
H = 64 mm
PAGEPRESET = A4
UNITS = mm
```

Equivalent URL format:

```text
https://www.templatemaker.nl/en/cone/?BOTTOM=226&TOP=34&H=64&PAGEPRESET=A4&UNITS=mm
```

This template was used to generate the paper guide for the big behavioral-arena screen and to identify/check the midline.
