# Projection alignment

Use this folder for files related to projector, mirror, and conical-screen alignment.

Add:

- calibration grid image
- projection-analysis PDF
- alignment photos or notes, if approved

The calibration grid should contain concentric circles, radial spokes, and crosshairs.

The projector, mirror, and cone should be mechanically aligned first. Software offsets should only be used for small residual errors.
