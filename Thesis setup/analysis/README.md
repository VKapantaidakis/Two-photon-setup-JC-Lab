# Analysis scripts

This folder is reserved for analysis code used after acquisition.

## Folder layout

- behavioral: tracking and behavioral response analysis
- calcium_imaging: fluorescence extraction and response analysis
- projection: projection geometry and calibration calculations

## Behavioral analysis

Add scripts used to extract fly position frame by frame and quantify locomotor activity, chamber occupancy, and responses to projected dot stimuli.

## Calcium imaging analysis

Add scripts used to extract fluorescence signals from regions of interest, calculate fluorescence changes relative to baseline, and align responses to black-white stimulus epochs.

## Projection analysis

Add calculations used for conical projection geometry, optical distances, and transformation validation.

Raw videos and imaging files should not be committed here unless a separate data-release plan is approved.
