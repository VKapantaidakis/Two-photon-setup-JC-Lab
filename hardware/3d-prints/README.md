# 3D printed parts

Optomechanical posts and post holders from the **PLAb: Optical Posts and Post
Holders** system by **Louis Edelman (@LowBoom)**:

  https://www.printables.com/model/1729832-plab-optical-posts-and-post-holders

The published set has 14 files (8 holders, 5 posts, 1 example assembly). Only
the two variants used on this rig are mirrored here.

| File | Part |
|---|---|
| `post_L50_A_M6.step`        | optical post, 50 mm, variant A, M6 |
| `holder_w50_h75_lr_M6.step` | post holder, 50x75 mm, left/right, M6 |

Exported from Onshape as STEP AP242.
